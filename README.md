# Agentic Development

Seven evidence-driven development Skills with optional observation hooks.
Install this Git distribution using Goose. Skills need no build.
Hooks require Python 3.10+ and use contained scripts/observe.pyz;
no pip, npm or network dependency download runs during installation.

Author source and contribute on develop, not main:
https://github.com/bioinfornatics/agentic-development/tree/develop

This artifact binds committed source; installation and review evidence
remain separate. Instructions and diagnostics do not approve coding outcomes.
