# User documentation

Keep this directory pedagogical, concise and directive. Each guide answers a user
question with an actionable sequence and one useful example. English is the canonical documentation language. Write guides, examples and instructions
in English unless the user explicitly requests a localized version. Keep translations
separate and linked to their English source; conversation language is not an exception.
GitHub Pages setup/publication is separate scoped work, not implied by guide edits.
Link to source references only for optional depth.
Do not put execution logs, JSON, task IDs, historical decisions, receipts or handoffs
here. Store run evidence outside this directory; Beads owns task status. Avoid a JSON
navigation index and repeated catalogs. Check changed links, not a blanket build.
