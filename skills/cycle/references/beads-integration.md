# Conditional Beads integration v1.1.0

Apply only when the repository uses Beads; this is a bridge, not a CLI manual.

## Obtain current operating instructions

- Verify the intended repository/workspace and installed `bd` capability.
- Use local Beads guidance and fresh injected context; run `bd prime` only when
  missing or stale. Read the complete output; use `bd <command> --help` as needed.
- Empty prime output does not prove an empty database: inspect `bd where`.
- Follow current user/project permissions over suggested prime close/Git/sync
  steps. Loading this bridge never authorizes installation, initialization or hooks.

## Connect the phase to task truth

- Read the actual task and blockers before choosing work; verify ownership/claim
  before implementation. Missing access or a failed claim is a blocker, not
  permission to continue untracked or invent IDs. Return the exact prerequisite.
- Beads owns status, dependencies and durable follow-up. Phase artifacts and
  restart prompts supply evidence, not a competing task database.
- One coordinator owns updates per issue; workers return findings and evidence.
  A claim grants neither overlapping file ownership nor Git authority.
- Record actual progress, criteria, proof locators, blockers and restart action
  when authorized; verify updates/closure by readback. Preserve incomplete work.
- Close only authorized, evidenced issue scope under the phase review gates;
  passing tests, session end or a commit does not approve a parent/US/release.

## Post-closure commit evaluation

- After each confirmed closure, evaluate perform / propose / skip / blocked;
  account for already committed work. Explain the decision in the phase report.
- Evaluation is not permission to commit. Use the entrypoint-linked commit
  safeguards for exact owned/staged paths and verified receipts. Never auto-push.
- Git publication and Dolt synchronization need separate scoped authority. JSONL
  is an optional export, not live task truth or a full Dolt backup; do not import
  or edit it to synchronize status. Report local-only or failed persistence honestly.
