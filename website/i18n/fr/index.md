# Agentic Development

Une méthode pour conduire un changement logiciel du besoin à la vérification,
en conservant le contexte entre tâches, commits et sessions.

## Commencer

1. [Décrire une première tâche](getting-started.md).
2. [Comprendre le cycle — en anglais](../../guides/cycle.md).
3. [Relier tâches, commits et sessions — en anglais](../../guides/integrations.md).
4. [Contribuer — en anglais](../../guides/contributing.md).

Chargez **agentic-development:drive-cycle** pour coordonner le parcours. Les tests
fournissent des preuves, pas une acceptation automatique.

## Traduction partielle

L'[édition anglaise](../../index.md) est la source canonique. Seul le guide
Démarrer est traduit pour ce prototype. Les autres guides restent en anglais :
aucune traduction manquante n'est présentée comme disponible.
Le sélecteur de langue ouvre l'accueil de l'édition choisie ; le guide Démarrer
propose aussi un lien vers la page anglaise équivalente.

Le site est un prototype local Zensical ; aucune publication GitHub Pages
n'a été effectuée. L'interface de recherche Zensical reste actuellement en anglais,
même si elle permet de chercher le contenu français.
