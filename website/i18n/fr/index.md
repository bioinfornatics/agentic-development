# Agentic Development

Conduisez un changement logiciel du besoin utilisateur à la vérification,
en préservant le contexte entre tâches, commits et sessions.

## Partir d'un résultat observable

1. [Décrire votre première tâche](getting-started.md).
2. [Piloter le cycle de développement](cycle.md) : Research → Plan → Implement → Test → Judge → Iterate.
3. [Relier tâches, commits et sessions](integrations.md).
4. [Contribuer à la méthode](contributing.md).

Chargez **agentic-development:cycle** pour coordonner le parcours, ou utilisez
une seule phase si votre demande se limite à celle-ci. Les tests fournissent des preuves,
pas une acceptation automatique.

## Langue et périmètre

L'anglais est la source canonique. L'édition française est un miroir complet des
cinq pages anglaises, avec les mêmes sections et le même ordre de navigation.
Les traductions restent séparées et liées à leur source anglaise.
