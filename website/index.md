# Agentic Development

Take a software change from a user need to verification, preserving context
across tasks, commits and sessions.

## Start with an observable outcome

1. [Describe your first task](guides/getting-started.md).
2. [Steer the development cycle](guides/cycle.md): Research → Plan → Implement → Test → Judge → Iterate.
3. [Connect tasks, commits and sessions](guides/integrations.md).
4. [Contribute to the method](guides/contributing.md).

Load **agentic-development:drive-cycle** to coordinate the workflow, or use one phase
when that is all your request covers. Tests provide evidence, not automatic acceptance.

## Language and scope

English is canonical. The [French edition](i18n/fr/index.md) currently includes
only Getting started. Other guides remain available in English; translations
are separate and linked to their source. The header language selector opens
the chosen edition's home; Getting started also links to its equivalent page.

This is a local Zensical prototype, not a deployed GitHub Pages site.
The [portable phase core](../plugins/agentic-development/README.md) is separate from the optional harness.
