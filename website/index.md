# Agentic Development

Take a software change from a user need to verification, preserving context
across tasks, commits and sessions.

## Start with an observable outcome

1. [Describe your first task](../docs/getting-started.md).
2. [Steer the development cycle](../docs/cycle.md): Research → Plan → Implement → Test → Judge → Iterate.
3. [Connect tasks, commits and sessions](../docs/integrations.md).
4. [Contribute to the method](../docs/contributing.md).

Load **agentic-development:cycle** to coordinate the workflow, or use one phase
when that is all your request covers. Tests provide evidence, not automatic acceptance.

## Language and scope

English is canonical. The French edition is a complete mirror of the five English
pages, with the same sections and navigation order. Translations remain separate
and linked to their English source.
